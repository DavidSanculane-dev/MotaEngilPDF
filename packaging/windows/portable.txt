Versa PDF portable mode

While this file sits next to pdfcraft.exe, Versa PDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the compatibility-preserving PdfCraftData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Versa PDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Versa PDF and
%LOCALAPPDATA%\Versa PDF) instead. If PdfCraftData can't be written (for example on a read-only
drive), Versa PDF says so and uses the per-user folders instead.
